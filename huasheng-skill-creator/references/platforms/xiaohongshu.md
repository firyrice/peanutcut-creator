# 小红书算法拆解

## 推荐机制

小红书和抖音、B站最大的不同是：**它本质上是一个"搜索型社区"，而不是纯"信息流推荐"产品**——大量流量来自用户主动搜索关键词而不是被动刷推荐，这决定了小红书的内容运营逻辑和纯信息流平台有本质区别。

- **去中心化 + 搜索双轨分发**：小红书的流量分两条腿走——一条是推荐流（首页"发现"页的兴趣推荐，机制上和抖音类似，也是分层放量、赛马晋级），另一条是搜索流（用户主动在搜索框输入关键词找答案），行业观察中搜索流量在小红书大盘中的占比明显高于抖音、B站等纯推荐产品，很多爆款笔记的长期流量甚至主要靠搜索沉淀而不是推荐流冷启动那一波。
- **CES评分（点赞/收藏/评论/关注加权）**：笔记发布后进入基础流量池测试，系统综合点赞率、收藏率、评论率、关注转化率等互动数据打一个综合分（业内称"CES"，官方未公开具体权重和名称），分数达标才能进入下一层更大的流量池，机制上仍是分层赛马，但小红书对**收藏**这个信号的敏感度明显高于点赞——收藏代表"这条内容我认可到愿意留着以后用"，比点赞这种低成本的情绪化互动更能代表内容真实价值，这也是为什么小红书的干货类、攻略类笔记即使点赞不多，只要收藏率高，也能获得持续推荐。
- **笔记进入流量池赛马**：和抖音一样是"小池子测试→数据达标→放量到大池子"的逐级过程，但小红书每一层给内容的"考核周期"通常比抖音更长——一条笔记发布24-72小时内的数据表现都可能影响后续放量，不是像抖音那样几分钟内见分晓，这意味着笔记发布后的头几个小时依然重要，但后续的持续互动（比如评论区被翻出来讨论）也能带来"二次起量"。
- **长尾搜索复访**：一篇笔记只要标题和正文里的关键词覆盖到了用户会搜的词，即使推荐流冷启动没有起量，也能靠搜索长期获得稳定的、免费的曝光——这是小红书区别于抖音、B站最大的流量红利：内容的"保质期"更长，一篇写得好的攻略笔记可能在发布半年、一年后依然通过搜索给你带来流量，这决定了小红书更适合做"内容资产"而不是"一次性爆款"。
- **封面即第一入口**：小红书首页"发现"页是双列瀑布流卡片展示，用户先看到的永远是封面图+标题这两行信息，再决定点不点进去——封面在小红书的权重和地位，接近抖音"开头3秒"+"标题"的组合体，因为瀑布流的浏览方式让封面承担了比抖音信息流更重的"第一眼决策"责任。

## 核心指标与权重

按重要性排列，每个指标对应的内容杠杆：

1. **CTR（封面+标题）与搜索关键词覆盖**（权重极高，两者并列第一位）
   - 内容杠杆：**封面大字报化**（封面上直接放3-8个字的强结论/强利益点，比如"3个月瘦15斤""这样穿显高10cm"，瀑布流场景下用户不会为了猜悬念点进去，要直接给答案的预告）、**标题里前置埋入用户会搜的关键词**（写"人生第一支香水推荐"而不是"我的用香分享"，标题既要吸引点击也要覆盖搜索词，两个目标同时兼顾）、**正文和话题标签里重复关键词的不同表达形式**（同义词、场景词都埋一遍，扩大能被搜到的词覆盖面）。
2. **收藏率**（高于点赞，权重排第二）
   - 内容杠杆：**做"以后要用得上"的干货内容**（清单、攻略、模板、教程类内容天然收藏率高，用户当下可能不点赞但会先收藏防止刷过去找不到）、**在正文或封面里提示"建议收藏"**（比抖音的"三连"引导更自然，小红书用户对"收藏"这个动作的接受度天然更高）、**内容要经得起"回看价值"检验**（信息密度高、可复用性强的内容才配得上被收藏）。
3. **互动率**（点赞/评论/转发/关注）
   - 内容杠杆：**留提问或争议点促评论**（"你们觉得哪个好用？评论区聊聊"）、**评论区第一时间回复**（小红书用户对评论区互动的期待值高，博主回复能带动更多人跟评，进一步推高互动分）、**结尾埋关注钩子**（"后续还有第二篇，关注不迷路"）。
4. **完播率**（视频笔记适用，权重相对最低）
   - 内容杠杆：视频类笔记依然要控制节奏、前几秒给价值预告，但因为小红书大盘里图文笔记占比高、完播率不是所有内容形态都适用的指标，这条杠杆的优先级明显低于封面标题和收藏，做视频笔记时不必像做抖音号一样把全部资源砸在"卡点留人"上。

## 内容形态适配

- **竖屏3:4封面（1242×1660比例）**：小红书首页瀑布流的图片卡片默认按3:4的竖版比例裁切展示，无论图文还是视频笔记，封面都要按这个比例预先设计构图，横图或1:1的图直接被裁切后往往会丢失关键信息或显得局促。
- **封面标题党+大字**：封面文字设计要像"公众号标题党"一样直给——大字号、强对比色、结论先行，不需要含蓄或留白，小红书用户在瀑布流里给每张封面的决策时间比抖音信息流更短（因为同屏能看到两列多张封面同时比较）。
- **正文含关键词与话题标签**：正文开头第一段要把核心关键词自然写进去（兼顾搜索收录和用户快速判断"这条是不是我想要的"），文末加3-8个话题标签（#标签），标签要覆盖从大词到细分长尾词的不同颗粒度，扩大被搜索和被推荐命中的概率。
- **图文与短视频并行**：小红书不是纯视频平台，图文笔记（多图+文字说明）在很多垂类（美妆、家居、教程类）的流量表现不输甚至优于视频，选择内容形态时要按垂类和内容性质决定，不是所有内容都要拍成视频。
- **"干货体"结构**：小标题分点、数字列表、前后对比图、步骤截图是小红书内容的标准结构语言，用户习惯这种"一眼扫完能拿到重点"的排版，纯大段叙述性文字在小红书的完读率和收藏率通常明显偏低。

## 冷启动与破圈

- **关键词卡位**：发布前先搜一遍你要写的核心关键词，看当前搜索结果页排名靠前的笔记是什么结构、什么信息密度，找到当前"答案还不够好"或"信息还不全"的关键词空位，卡位一个搜索量存在但竞争内容质量一般的词，比硬拼一个已经被头部博主占满的大词性价比更高。
- **蹲搜索**：与其赌推荐流冷启动能不能起量，更稳妥的策略是先想清楚"用户会为这个需求搜什么词"，围绕这些词把内容写扎实，哪怕推荐流不给流量，搜索流量也能慢慢把这条笔记的长尾价值兑现出来——这是小红书独有的"打法保底"逻辑。
- **避免营销词限流**：小红书对广告痕迹重的营销词（"最便宜""全网最低""效果第一"等绝对化用语，以及明显的导流私信、微信联系方式）有明确的限流甚至清退机制，新号尤其要注意软性种草的表达方式，硬广措辞会直接影响笔记能否进入正常的流量池测试。
- **素人铺量**：品牌种草常见操作是找大量素人/腰部博主同时铺发相似角度的笔记，靠"多篇小声量笔记在搜索结果页形成密度"来影响用户对该产品/话题的认知，这种打法本质是利用小红书搜索流量占比高、单篇爆款不是唯一出路的特性，个人博主同样可以借鉴"多篇小笔记覆盖不同关键词角度"的思路而不是死磕一篇爆款。
- **爆文结构复用**：在你的垂类里找到验证过的爆款笔记，拆解它的封面结构、标题公式、正文分段方式，套用到自己的选题上（换内容不换结构），小红书内容的结构化程度高，同一套"结构模板"复用的成功率通常比完全原创结构更稳定。

## 一句话打法

小红书是搜索与信任感的战场：封面标题给结论、正文标签埋关键词，靠干货换收藏、靠收藏换长尾搜索流量，关键词卡位比死磕推荐冷启动更稳，营销词红线不能碰。
