# 账号长记忆方法论（生成器内核）

这是生成 `references/skill-template/account-memory.md.tmpl` 时的"抄数据来源"，与 cover-design.md / script-writing.md / data-tracking.md 等并列。它讲的是**跨平台、跨垂类**的"账号长记忆（huasheng）"机制；产物生成时把模板落成产物自己的 `workspace/huasheng.md`——一份**每次开工前必读**的长期记忆文档。

## 为什么每个账号都要有一份长记忆

创作若不沉淀，就永远是开环的：这条为什么爆、那条为什么扑，全凭感觉，做十条和做一条没有区别。长记忆是把"账号越做越懂自己"这件事**落成一个文件**——它记三样东西：

1. **你是谁**（人设 / 定位 / 受众）——生成时就预置好，稳定不常改。
2. **每期固定的品牌口令**——逐字复用的声音指纹（见下）。
3. **从数据复盘里沉淀的规律**——带置信度，越做越厚，是"数据 → 复盘 → 反哺创作"闭环的落脚点。

选题、文稿、标题、封面动笔前都先读它，让每一条新内容都站在过往所有经验之上，而不是从零开始。它是账号的"大脑和记忆"，与 workspace（当前工作台）、content-db（跨重装长期库）三者分工明确。

## 生成时预置 vs 运行中生长（两类内容别混）

- **生成时预置死**：账号名、平台、垂类、人设、目标受众、受众心声、差异化定位、内容方向、**品牌口令**。这些在阶段2诊断确认后已经确定，生成产物时直接写进 huasheng.md 第一、二节，用户装上就有，不是空壳。
- **运行中才长出来**：流量基线（要等发够 5–10 条视频回算真实水位）、累积规律（要等复盘才有）。这两节生成时留结构 + 留空 + 写清"怎么填"，不硬编造数字。

## 品牌口令：按账号定制的声音指纹（重点）

品牌口令是每期视频里**逐字复用**的固定用语，通常是一句开场品牌锚 + 一句结尾价值锚 / CTA。它是账号区别于同垂类其他账号的听觉记忆点——观众听多了会形成条件反射（"哦是这个号"）。

**必须按账号定制、与账号名+人设高度一致，绝不能做成大家都一样的通用模板。** 生成产物时，基于确认后的账号名和人设**现场创作**这两句，判据：

- **含账号名或其变体**，让口令自带品牌露出（如账号名"大厂过来人老K"→开场可含"我是老K"/"关注大厂过来人"）。
- **口吻贴人设**：过来人前辈是掏心窝的口气，专业测评师是干脆利落的口气，段子手是玩梗的口气——口令的语气必须和人设一致，不能人设是毒舌但口令是官腔。
- **一句话能记住**：短、上口、有钩子或价值承诺，不要写成冗长的自我介绍。
- **开场锚**通常放在 hook 之后（先抓人再报名号，别一上来就自我介绍浇灭钩子）；**结尾锚**承担价值总结 + 关注引导。

反例（通用、可套在任何号上，禁止）："大家好，欢迎来到我的频道，喜欢的话点赞关注。"
正例（绑人设+账号名，某"大厂过来人"职场号）：开场"我是老K，一个从大厂中层裸辞出来的过来人，只跟你说真话不灌鸡汤"；结尾"想清楚了再动，别慌——关注老K，帮你把职场里的糊涂账算明白"。

不同账号的口令必然不同，这正是要点。生成后在交付说明里把这两句列给用户，告知可自行微调，但提醒：**一旦定下尽量别改**，改口令等于换声音指纹，牺牲已积累的记忆点。

## 反哺闭环：复盘规律怎么回写长记忆

这是数据追踪那一环的下游、也是长记忆"生长"的机制，和 [data-tracking.md](data-tracking.md) 联动：

1. 发布后数据追踪脚本刷新 `workspace/账号数据/` 与各视频 `数据/`。
2. 复盘（`workspace/reports/`）追问"为什么"，得出稳定结论。
3. **把稳定结论回写进 huasheng.md 第四节"累积规律"**，每条带置信度标签（🔒已多次验证 / 🟡初步观察 / ⚪待验证）与依据（哪次复盘、哪几条数据、日期）。
4. 基线水位变化时更新第三节"流量基线"。
5. 下一轮开工前读到这些规律——避开已知的坑、复制已验证的打法。

关键纪律：**规律要可执行、带置信度、带依据**，不是把数字抄一遍。一条"🔒 mega-cap 白马 + 全网热点 = 涨粉黑洞（依据：8-18 全量横评 9 条数据）"这样的规律，才真正能在下一次选题时拦住一个坑。置信度随验证次数升级（⚪→🟡→🔒），被推翻的规律直接删。

## 落地要点（生成产物时）

- 产物必带 `workspace/huasheng.md`，从 `account-memory.md.tmpl` 填空生成，第一、二节预置真实内容（不留 `{{...}}`、不留空壳），第三、四节留结构+留空+写清填法。
- 产物 SKILL.md 的"前置步骤"里把"开工前必读 huasheng.md"列为动笔前第一件事。
- 产物 `references/workspace-guide.md` 的顶层结构里列出 `huasheng.md` 并说明其地位。
- 品牌口令同时是分镜模块 A Roll 正面清单里"品牌锚/CTA 结尾"的取值来源——口播稿写到开场/结尾时直接用 huasheng 里的定稿口令。
