# 文稿方法论核心（跨平台/跨垂类通用内核）

> **定位说明**：本文是文稿写作判断逻辑的**通用内核**，只讲跨平台、跨垂类都成立的判断逻辑，不涉及任何平台的具体时长、形态数值（竖屏短视频的秒数上限、横屏长视频的分钟区间等）。这些平台专属规则在生成产物时，从 `references/platforms/*.md` 里对应平台的资料注入，与本文的通用逻辑叠加使用；不要把某一个平台的具体时长（比如"60秒"）当成通用规则写进这里，也不要在没有平台资料注入的情况下凭空编一个时长交付给用户。

## 一、写稿前：平台适配评估 + 情绪弧线草图

**写第一个字之前必做两件事。**

### 1.1 平台适配评估

拿到选题后，先判断：**这个选题，能在平台允许的最短内容时长里，把最核心的一个结论/冲突/反常识讲清楚吗？**

- **能** → 短平台版聚焦那一个点，不要试图塞进去更多
- **不能** → 短平台版**不是长版的平均压缩**，而是从长版里找出最有冲击力、最挑战常识、最有煽动性的那一个结论或问题，单独拎出来，只把这件事讲透

**禁止**：把一个需要完整逻辑链才能讲清楚的选题，硬压缩成面面俱到但每个点都浅尝辄止的短内容。宁可短版只讲一件事讲透，也不要讲五件事每件都讲烂。

### 1.2 情绪弧线草图

在写第一个字之前，先在脑子里设计这条弧线：

```
开头情绪：观众点进来时是什么感受？（担忧？困惑？好奇？）
↓
中间转折：我要在哪里给他一个"原来如此"的时刻？
↓
结尾情绪：我希望观众看完是什么感受？（安心？愤慨？有底气？想转发？）
```

信息是服务于情绪弧线的，不是反过来。写完后自查：如果把所有情绪词去掉，观众还剩什么感受？剩下只有"信息"没有"感受"，说明稿子缺灵魂，要重写。

## 一·五、留存单元制（贯穿全篇的核心结构心法）

一条能跑赢推荐算法的长视频，本质是**若干个彼此高度关联的短视频单元咬合而成**，每个单元自带一个"看完这个还想看下一个"的引信。这是留存设计的总纲，下面所有结构规则都服务于它。

- **单元 = 一个钩子 + 一个观点 + 若干论证/案例 + 一个小结**。写之前先把整条内容切成 4–6 个这样的单元，列出每个单元的"进钩子"和"出钩子"，再动笔。判断标准：把任意一个单元单独拎出来，它自己就是一条完整的短视频。
- **单元收尾不收心**：每个单元结束时不要把话说圆、让观众有"听完了"的满足感，而要再抛一个新悬念（rehook）把人推进下一个单元。
- **rehook 用叙事转折，不用裸设问**：❌ 连着用"那么到底是谁在动手脚呢？""可这还不是最坑的——"这类直白设问当接缝，观众能闻到套路味。✓ 用故事本身的转弯拽人——"但他接下来说的一段话，让我也笑不出来了"。叙事驱动的接缝比修辞驱动的自然得多，优先用人物/事件的转折。

## 一·六、一条视频只讲透一个核心概念

- **概念做减法**：两个概念在这条内容里功能重叠（都在说同一件事），删掉一个，只留最锋利的那个——观众记不住两个黑话。宁可一个概念挖到底、配足案例，也不要为显得"懂得多"平铺两三个概念（稀释记忆点、拖垮节奏）。一个偏离主线但"写得还不错"的段落，该砍就砍。
- **"递进下探到根"是合规的多层结构，别和"平铺多个概念"搞混**：禁的是**并列**（把功能重叠、谁也不比谁更根本的两三个概念摆一排，稀释记忆点）；祝福的是**下探**（同一条主线上，第一层给个像样答案，再自我否定"这还不是真正的原因"，逼出更深一层，挖到根）。每下探一层都是一次天然 rehook。但下探有两个致命陷阱，比"不敢深挖"更常见：
  - **陷阱一·偷换问题（每一层都必须还在回答标题那个问题）**：追"更深一层"时，极易在不知不觉中换成回答**另一个问题**。真实案例：标题问"这道菜为什么长这样"，下探却答成了"为什么是这群人做这道菜"——后者再深刻也跑题了，观众会立刻闻到"逻辑跳跃"。做法：每挖一层，回头对一次标题——这一层还在回答开头那个问题吗？不是，就要么把它拉回主问题，要么留作下一条选题，别硬塞。
  - **陷阱二·最深一层选"最普世可迁移"的，不是"最煽情"的（戏剧性≠深度）**：留存导向写法会把人往"敢下判断、情绪脊椎"推，于是最深层很容易选一个戏剧性最强、最能煽情的答案。但真正压得住的最深层，应该是那个**最普世、最能把观众自己卷进来**的机制——它能把"远方某群人的一段奇事"升级成"一条碾过所有人（包括你）的普遍规律"，情绪也随之从"隔岸叹气"变成"后背发凉"。判断：这个"根"只解释了这一个案例，还是能解释一大类现象、还能解释到观众自己身上？越普世越该选它当底。（煽情的那层不必扔，降级成"这股力最极端的一个例子"塞进去即可，别让它冒充根。）

## 一·七、手艺层：决定"有没有魂"的四样（最值钱、最难，别偷懒）

规则能保证"不难看"，但一条视频有没有魂靠下面四样，它们是刻意的选择、不是套路：

1. **具体压倒抽象**：不要写"一个博主""有些人"这种没脸的示意图。造一个具体的人、给名字、给一个**荒诞又可信**的细节（一个怪到让人追问的数字、一个好笑又心酸的举动），抽象概念挂在具体的人身上才有代入感和记忆点。**合规护栏**：这种"我一个朋友…"的角色是合法叙事装置（观众默认为演绎），和"把虚构当真实信源"是两回事——真实事件/数据标信源、不确定就说不确定；虚构人物细节落在明确的演绎框里。两者不能混。
2. **有一个真敢下判断的"我"**：观众要的不是念维基百科的人，是一个真信点什么、敢亮立场的人。在人设允许范围内给出有锋芒的观点（哪怕只是温和反某种主流叙事），锋芒才激发评论转发，纯科普会被划走。别下意识为"中立安全"把话说得四平八稳。
3. **把道理压成一个能成像的意象**：观众最后往往只记住一个画面。别用"骨架""基石"这种用烂的比喻，想一个原创的、能成像、还呼应主题的意象（如"一块铁矿被淬火成齿轮形状，再扔回群山之间就格格不入"同时做了讲道理/给情绪/留记忆锚点三件事）。
4. **具体的梦替代抽象的分类**：讲解法/愿景时不要写"尝试自由职业"这种名词，写"开个海边的咖啡店""做个一年只上两个月班的地接导游"——观众没法向往一个词，但能立刻看见一个画面。
5. **能用真实的"我"就别用虚构角色（真我 > 编造的角色）**：第1条讲"造一个具体的人"，但那是退路不是首选。若账号人设允许（尤其"平视同好/过来人"这类第一人称人设），**用创作者自己真实的经历/感受落地抽象**，比造虚构角色代入更强、且零合规风险（不用担心把演绎当真信源）。顺序：能用真我→用真我；用不上再造明确演绎框里的虚构角色。
6. **梗即论点，不是调味（最高级的玩梗把论点压进一个词）**：语域下沉不只是加网感。最好的梗本身**承载信息**——把一个论点压缩进一个字/一个词，观众笑的同时就把论点记住了。案例："左宗**糖**鸡"一个错别字，把"这道菜被美国人改甜了"这个核心论点缝进了菜名里。别把梗当外挂调味料，让它干活。
7. **用一个案例的"内部前后变化"演示抽象机制（活体证据）**：讲抽象机制（如"环境会改造事物"）时，与其讲十句道理，不如找一个案例、让它在观众眼前**自己变一遍**。案例："同一道菜、同一个发明人，只是跨了一趟太平洋，就从咸辣变成了甜脆"——没人重写菜谱，可它就是变了，这本身就是"环境改造事物"最有力的活体证据。比任何论述都狠。
8. **禁元评论：别替观众预告反应（"怪/好笑/荒诞/震惊"）**：一个事实如果真的怪、真的荒诞，观众自己会反应过来——你跳出来贴一句"你就不好奇吗""这名字怪不怪""你品品这个荒诞""说来有点好笑"，等于替观众下结论，反而暴露你对这个事实不自信、说话方式做作，把劲泄了。把那些"怪怪的发现/这桩怪事/你有没有想过"里的评价词删掉，直接平铺事实本身（"招牌用的是一包松饼粉的名字"，而不是"你品品这个荒诞：招牌竟然是松饼粉"）。这与"具体压抽象、让东西自己说话"是同一条脊椎的反面：**事实够劲就直给，让它自己炸；需要你标注"这很精彩"的地方，往往是事实本身还不够劲。**

> **诚实提醒**：手艺层比规则层难得多，更像能力而非套路。尽全力做，但**绝不能为了"有具体细节"就把编造的事实伪装成真实信源**——宁可用"我一个朋友"的演绎框，也不要假造数据/人名/机构。

## 二、Hook结构

绝大多数平台的完播率曲线在开头阶段掉得最快，文稿开头的处理方式直接决定这条内容能不能活过第一轮流失。写文稿前先判断内容属于哪种结构类型，两种类型的开头写法完全不同：

- **Hook型内容**：开头就抛出结论、冲突或反转，核心矛盾或最强信息点在开场就出现，不铺垫背景。判断标准是——如果把这条内容的核心矛盾点直接放在文稿第一句，逻辑依然通顺，就属于Hook型。Hook型内容的开头必须在**前15秒内**完成"抛出钩子"的动作，这15秒基本决定了这条内容是被划走还是被留下。
- **非Hook型内容**：需要先铺情境、讲背景，核心信息在中后段才浮现，属于渐进式叙事。判断标准是——核心矛盾点如果直接放在第一句会显得突兀、缺乏上下文支撑，就属于非Hook型。非Hook型内容不强求前15秒抛出最终结论，但仍然要在开头制造一个悬念或疑问，让受众有理由相信"往后看会有答案"，不能因为是渐进式叙事就放任开头平淡。

判断错结构类型、给一个Hook型内容配一个铺垫式开头，会在最容易流失观众的前15秒浪费掉钩子；反之给一个渐进式内容硬套"前15秒抛结论"的写法，会导致结论提早暴露、后续内容失去悬念支撑。两种错配都要在写文稿前判断清楚。

**"钩子之前删自我介绍"不等于"全篇不能有自我介绍"**：常见铁律是"删掉'大家好我是…今天聊聊…'这类开场"——但删的是**钩子之前**的冷启动自我介绍，不是钩子之后的。有一种合法且好用的开场型叫**设问连缀式**：开头先连抛 2-3 个观众真会问的真问题（把好奇心勾起来），紧接着再"大家好，我是XX，这条视频就把这几个问题聊清楚"——此时自我介绍不再是冷启动铺垫，而是"我承诺给你解答"的**立约动作**，反而强化了"往下看有回报"的预期。判据：自我介绍前面有没有已经立住的钩子？有→合法；没有、上来就自我介绍→删。

**叙事/解谜型内容：故事一口气讲到底，别中途插说教（渐进式内容尤其高发）**：一条围绕"一件事的来龙去脉"展开的视频（一道菜的身世、一个品牌的沉浮），观众是顺着"然后呢"的惯性往下走的。最常见的破坏是：讲到一半突然按住观众，插一大段脱离故事的抽象科普或道理（"这背后其实是一套规则：……你有没有想过……"），讲完再用一句别扭的"不过这个故事最精彩的地方……"把观众硬拽回故事线。**那句把人拽回来的缝合句，本身就是"我刚才打断了叙事"的铁证——故事顺的话根本不需要缝。** 规则：叙事型内容里，中途只放"为后续剧情服务"的最小交代（后面要用到的设定点一句即可），把提炼的道理压到结尾、用故事本身演示一次（见手艺层"活体证据"），全片说教只出现一次、且在收口处。判断：删掉这段议论，故事还接得上吗？接得上→它就是插进来的，挪走或删。

**第一句必须含本选题最可搜索的主体关键词（硬约束）**：短视频/信息流平台的第一句口播会变成自动字幕，是平台拿去做搜索与推荐匹配的第一手素材。抛悖论/怪问题可以，但主体关键词必须坐在句子里，别为抖机灵把最该被搜到的词漏了。这与标题模块的"话题可辨识+关键词锚定"一致，只是延伸到文稿第一句。
- ✗ "为什么要禁掉一盏蓝灯？"（"蓝灯"太泛，看不出是智驾话题，白白焊死流量入口）
- ✓ "智驾的小蓝灯刚火没多久，为什么突然要被禁？"（怪问题和搜索关键词一句话齐了）

**hook 的时效核查（硬约束）**：hook 是整条视频的地基，跟当下现实冲突会让整段垮掉。hook 定稿前，把里面每一处"现状/时间/进展/数据"类断言（"…就快来了""还没…""已经…""即将…""目前是…"）逐条拎出来，**联网核当下真实状态**——模型知识可能过期，别凭记忆下判断，尤其警惕**把已经发生的说成将来时、把已经变了的说成没变**。核查对象是 hook 里的具体断言本身，不是泛泛搜选题（深挖搜过选题≠核过 hook 那句话的时效）。
- ✗ 选题"中俄永久免签"，hook 写"去俄罗斯一甩护照就能过的日子就快来了"——事实是中俄早已阶段性互免签证、只是"永久化"没落地，把"已经免签"说成"就快来了"，一句话暴露不懂常识、整条崩掉。
- ✓ 先核"当前免签到什么程度、这次新进展是啥"，hook 建立在准确的当下状态上（如"中俄免签又要往前走一大步"）。

## 三、节奏控制与信息密度

文稿的节奏本质上是信息密度的分布问题，处理不好会导致两种反向的失败：信息太密受众跟不上、太疏受众觉得废话多。通用原则：

- **每段一个信息点**：文稿按段拆解时，每一段应该只承载一个明确的信息点或论述单元，不要在同一段里塞入多个跳跃的信息点。
- **信息点之间要有清晰的过渡**：段与段之间的衔接要让受众明确感知到"上一个点讲完了，进入下一个点"，避免信息点之间无缝糊在一起让人分不清层次。用**预告式钩子**过渡，不用平叙式总结。
  - ✗ "说完了背景，我们再看看各方的利益。"
  - ✓ "但真正的问题在这——如果你把这件事里每一方的利益拆开来看，你会发现一个很反直觉的东西……"
- **节奏松紧随时长调整**：具体每分钟应该承载多少个信息点，这些数值随平台的典型时长和受众耐心阈值变化，从平台资料注入。

## 四、信息增量——每个观点必须超出受众的已知认知

这是决定内容有没有干货价值的核心判断。

**每个信息点交付前先问自己：这个观点，目标受众有90%的人已经知道了吗？如果是，就必须加深一层。**

加深的方式：
- 常识 + 具体数字量化：把常识变成可感知的程度
- 常识 + 反直觉推论：挖出和表面相反的底层逻辑
- 常识 + 延伸后果：把结论再往后推一步，给出普通人没算到的影响

讲常识=浪费受众时间=他们会划走。每个选题都有一批"这不是人尽皆知的吗"的点，这些点要么加深、要么删掉，不能原样保留。

**读者会追问的逻辑洞，往往正是深挖能出金子的地方（别糊过去）**：写完通读时，凡是自己都觉得"这里有点跳、观众可能会问一句为什么"的接缝，不要用一句含糊的话糊过去——那个洞十有八九藏着最好的料。真实案例：稿子讲"名字被人永久占了、只能改名"，但后文又出现"大公司自己开了同名店"，中间明显缺一环。去把这个洞填实，挖出来的是"那个商标1996年失效了、名字重新变成谁都能抢的空地"——一个既补上逻辑、又自带戏剧性、还印证全片主旨的硬事实。所以把"观众会在这儿追问什么"当成深挖的探针：**最扎眼的逻辑缺口，通常是这条选题里信息增量最高的富矿。**

## 五、比例感和程度感——数字必须通过对比才有冲击力

裸数字对受众没有感知价值。任何数字，只有通过对比或类比，才能让受众感受到"程度"。

**格式：[数字] + [参照物对比] = 程度感**

**参照物必须是受众日常能感知的东西**：家庭月支出、一顿饭的钱、一个月房租、一年工资、手机电量、家用车油箱……具体参照物因垂类和受众画像而异，生成产物时按账号的目标受众选择合适的参照系。

**禁止**：用受众没有感知基准的工业场景、专业设备、军事装备作参照物。"相当于X艘航母"——普通人对航母大小毫无感知，类比无效。

**举例两关自检（推广到全文一切例子/类比，不止数字参照物）**：例子是手段，目的是让人更好理解、更愿意信服。一个合格的例子必须同时满足两条，任一不过就换更近的、或删掉：
1. **它本身比你要论证的东西更好懂**——不能用一个更陌生、更需要解释的东西去解释一个没那么陌生的点（那是用更难懂的解释更好懂的，方向反了）。
2. **它落在大多数目标受众的日常经验里**——受众能用自己的生活验证它。验证不了、共鸣不了的例子就是在跑题、增加费解，严重时观众连你要讲什么都忘了。
**尤其警惕"洋例子/专业领域例子"**：显得高级有出处，但对大众受众往往更远。例：给中国观众讲"浏览器地址栏那个挂锁图标只证明加密不证明网站不钓鱼"——本身就比要讲的主题更难懂、也非国人日常经验，两关全踩雷，该删或换成本土日常的例子。

---

## 六、数据信源——每条关键数据必须说明来源

> **先于"有没有信源"的一步：每个论点后面必须跟一条硬论据，而不是把论点换个说法再说一遍。** 这是最常见、最难自查的失败——AI 尤其容易只给结论、或用一个更抽象的词复述论点，制造"解释了"的假象（循环论证：「它迎合，是因为它迎合」）。硬论据只认三种黄金形态：① **带对比锚点的冲击力数据**（"上桌吃饭比上战场危险166倍"，不是"很危险"）；② **有名有姓的真实人物**（那个坐椅子吃饭被打死的达利特木匠吉腾德拉·达斯，不是"有个底层人"）；③ **有时间地点的历史事件**（2019年北阿坎德邦那场婚宴，不是"曾经发生过"）——三者都要带信源。拍脑袋推理出来的"道理"不是论据，只是论点的复述。
>
> **反循环论证自检（写完通读，遇到每个"所以/因为/本质上是/说到底"就停）**：问一句——这后面跟的是一条能被核查的硬事实（数据/真人/真事件），还是我把上半句换了个词？是复述，就回去搜一条真的来。**注意：这个"去搜一条真的"的动作，和核实史实真伪本来就是同一件事——举证据和防造假是一码事，别把该核的去核、不想核的就绕开用推理。论证层要和事实层享受同等的检索待遇。**
>
> **想要更多戏剧性时，先验证那个情节真不真，别为"加戏"编一个没发生过的情节。** 创作者（或用户）常会说"这里能不能再挖点戏剧性细节"——危险就在这：戏剧性最强的那个版本，往往是没发生过的那个。真实案例：一个"小店抢注了商标、大公司来打官司"的故事，听着该有一场精彩庭审，可一核实，当年大公司是发现名字被占后**直接认栽改名、根本没打官司**——真正的官司是二十多年后另一件事。这时候顺着"深挖庭审细节"写，就必然凭空编造。做法：动笔加戏之前，先把"这个情节到底发生没发生"当成一条待核事实去搜；核不到就如实降级（"没有记载双方对簿公堂"），把戏剧性加在**真实存在**的那个转折上，而不是给需求硬造一个。

每条关键数据出现时，必须在稿子内部交代来源，自然嵌入口播，不要只在备注里写。

**来源交代的优先级：**
1. 官方信源最优先：具体到哪个部门、哪年的公开报告或发布会
2. 权威第三方机构：知名研究院、国际组织等，需说明机构名
3. 主流媒体报道：需说明媒体名

**禁止**：数字凭空出现没有信源，或只说"有数据显示"而不说是谁的数据。涉及国家安全、重大政策、军事能力等敏感内容，必须引用官方或主流媒体的公开信源，不能用分析机构的估算充当已知事实。

---

## 七、发展眼光看数据——现状+潜力才是完整的信息服务

讲到某个技术路线、政策方向或替代方案时，只讲现状等于讲了一半。受众要的是：**这条路能走多远？**

**写法格式：**
- 现状：目前规模/产能是多少（配参照物）
- 瓶颈：为什么还没到上限（成本？技术？政策？）
- 潜力：如果突破了瓶颈，上限在哪里（用数字算出来）
- 意义：这件事对受众意味着什么（情绪价值落点）

**典型错误**：讲某项技术只说"目前产量聊胜于无"——这是把技术储备等同于现有产能，忽视了极端情况下技术铺开的潜力。只讲现状不讲潜力，既损失了信息增量，也丧失了情绪价值（希望更可信，或威慑更惊悚）。

---

## 八、受众立场对齐——不能用中性词处理受众有明确情感倾向的事件

每个账号都有特定的目标受众群，这群人对某些议题有明确的情感倾向和立场预期。在这些议题上，"客观中立"不是真中立——受众会把中性词解读为偏袒对立方。

**原则：**
- 在目标受众有明确立场的议题上，措辞要对齐受众的感受，而不是使用外交辞令式的中性描述
- 叙述立场时，博主是受众群体里的一员，用"咱们"而不是把自己写成局外人
- 奥弗顿之窗因受众群体不同而有偏移，必须对齐你服务的那群人的窗口位置

**具体措辞由垂类和受众画像决定**，生成产物时注入。通用原则是：写完稿后问自己——目标受众读到这句话，会觉得博主站在他们这边，还是站在他们对面？前者对，后者重写。

---

## 九、稿子格式——结构标注不进稿子正文

写作时的内部结构标注（如【背景铺垫】【第二层】【钩子】等）是写作导航，**不能出现在最终稿子正文里**。

稿子必须直接可用于朗读、AI语音合成或字幕导入，不需要博主对着稿子一行行删标注。段落之间靠内容本身的钩子和逻辑衔接，不靠结构标注分隔。

---

## 十、完播设计

完播率不是靠内容本身的质量自然产生的，需要在文稿结构里主动设计留人机制。三个通用手段：

1. **悬念递进**：不要在开头把所有悬念一次性抖出来，而是设计成"解开一个小悬念的同时抛出一个新悬念"的链式结构，让受众始终有一个"还没解开的问题"驱动往下看。
2. **进度锚点**：在文稿中段适当位置插入明确的进度提示（比如"前面两个原因讲完了，第三个才是重点"），让受众清楚自己看到了整体进度的哪个阶段，降低中途划走的概率。
3. **"然后呢"感**：每一个信息点讲完后，文稿要自然引出受众心里"那然后呢/所以呢"的追问，再顺势给出下一个信息点作为回应。

---

## 十一、互动引导

互动数据（评论、点赞、转发、收藏）是绝大多数平台推荐算法的重要权重项，文稿需要主动设计互动引导点，而不是被动等待受众自发评论。做法：

- **自然植入提问或争议点**：在文稿的某个自然节点（通常是结论给出后），植入一个开放性问题或轻度争议性观点，引导受众在评论区表达看法。不能是结尾生硬加一句"欢迎评论区讨论"，这种硬贴的互动引导转化率很低。
- **争议点的强度要可控**：争议点必须是创作者基于内容真实持有的判断，只是表达方式留了讨论空间，不是无底线博眼球。
- **匹配平台互动权重**：应该往哪种互动行为引导（评论/收藏/转发），从平台资料注入。

---

## 十二、兑现标题承诺

文稿是对标题许下的承诺的具体履行，两者必须一致，不能各自为战。

- 如果标题是**好问题型**，文稿必须清楚地给出这个问题的答案，不能模糊带过。
- 如果标题是**清晰结论型**，文稿必须提供支撑这个结论的具体论据或案例。
- 如果**标题里有大数字**（巨大金额、极端比例、重大伤亡），文稿开头的冲突陈述必须快速围绕这个数字展开，前段内给出"这个数字意味着什么"的具体答案——观众进来看半天没有信息兑现就会划走。

判断标准是：文稿写完后，回头把标题重新读一遍，问自己"这条文稿有没有把标题许下的愿望兑现给受众"，兑现不了就说明文稿核心内容和标题核心主张出现了错位，需要调整。

---

## 十三、通用质量自检

不论平台和垂类，一份文稿在交付前都应该能通过以下自检，通不过就重写而不是硬凑：

1. **平台适配评估做了吗**：短版是最强一个点讲透，还是长版的平均压缩？
2. **情绪弧线设计了吗**：开头情绪→中间转折→结尾情绪，三个节点明确了吗？
3. **开头类型判断正确**：Hook型内容前15秒内有钩子，非Hook型开头有悬念，没有错配。
4. **信息增量达标**：每个信息点问过"90%受众是否已知"了吗？常识都加深了一层吗？
5. **数字都有参照物**：每个数字配了普通人能感知的类比了吗？
6. **数据都有信源**：关键数据说明来源了吗？敏感内容用的是官方信源吗？
7. **技术/政策有潜力分析**：用"现状+潜力"格式了吗，还是只讲了现状？
8. **受众立场对齐**：措辞对齐目标受众的感受了吗，还是用了中性词？
9. **稿子正文无结构标注**：所有【】标注都从正文里删掉了吗？
10. **每段一个信息点**：逐段检查，没有一段塞了多个跳跃信息点。
11. **"然后呢"测试**：逐段读完，每段结尾自然引出下一段，没有流失点。
12. **互动点自然且克制**：互动引导植入位置服务于内容逻辑。
13. **标题承诺已兑现**：回读标题，文稿给出了明确答案或充分论据；标题有大数字的，开头快速兑现了。
14. **论据不是复述（反循环论证）**：每个"所以/因为"后面跟的是硬论据（带锚点数据/真人/真事件+信源），不是把论点换个词重说？
15. **下探没跑题、最深层够普世**：递进下探的每一层都还在回答标题那个问题（没偷换）？最深一层选的是最普世可迁移的机制，不是最煽情的那个？
16. **没有替观众贴反应标签**：删干净了"怪怪的/这桩怪事/你品品这个荒诞/说来有点好笑"这类元评论？事实是直给、让它自己炸，而不是我先标注"这很怪/很精彩"？
17. **叙事型没被说教打断**：解谜/故事型内容里，中途没有插脱离剧情的大段道理？说教只在结尾出现一次、且用故事本身演示？

> **补充说明**：本文只提供跨平台都成立的文稿判断逻辑。具体时长与形态（竖屏短视频、横屏长视频等）由平台知识库在生成产物时注入，本文不写死任何时长数值。

## 终审关卡（交付前强制，必须"换一双眼睛"，不可用自评断言代替）

写完文稿会有一股"这条做完了"的完成感，紧接着最顺手的下一步往往是存档或收尾——终审恰好卡在"写完"和"下一步"中间，最容易被这股惯性直接跳过。所以先把话说死：**终审不是收尾润色，是这条流程里最不能省的一步，它防的就是"作者自己觉得没问题"**。写代码有编译器报错兜底，审文稿没有——越是没有外部反馈的步骤越依赖不偷懒，这里恰恰最容易松。三条铁规矩，生成产物时必须原样带进产物的文稿模块：

1. **必须换一双眼睛，不能作者自己再读一遍充数。** 首选用当前环境的子 agent 能力（Claude Code 的 Task/Agent、Codex 的等价能力）起一个**独立的审核 agent**做对抗性终审，喂给它三样输入——①定稿全文；②本账号的受众画像与受众心声；③Step 0 掌握的"这件事当下的公共认知水位"，让它按下面清单逐项审。环境实在起不了子 agent，就做一次硬隔离复审：彻底清空作者视角重新逐条核。作者对自己写的东西有盲区，这一步的全部价值就在"另一双眼睛"。

2. **只认逐条核查结果，不认一句自评断言。** 严禁用"已检查、合规、兑现承诺、信源齐全"这类概括声明代替终审——那是凭写作印象下的断言，不是核查，还会制造"已经查过"的假象，比漏查更糟。唯一合法产出：**逐项写出结论，问题项把原句抄出来 + 指出病灶 + 给出改法**。

3. **不过就打回重写，改完重审，绝不允许"大差不差"放行。**

### 第一层·硬门禁（二值，逐条核对，任一不过即打回）

1. **零结构标注**：成稿只留能念的正文，不能有【】小标题、段落功能标注、时间轴标记、括号里的导演/朗读提示——TTS 会一起念出来。
2. **零废话过场**：删掉没有信息增量的过场话和自我预告（"我们先把事实讲清楚""这是最关键的一点""我用最直白的话告诉你"）。判断法：删掉这句信息有没有少，没少就删。
3. **信源主体明确**：每处引述说清主体和时间，禁止"有分析师认为""据报道"这类无主体信源。
4. **前后不自相矛盾**：数字、比喻、分类、结论前后一致（如开头说"两只手"后文冒出第三只手）。
5. **提问必须有交代（开放问题全篇最多一个）**：每个问题要么明确回答、要么留给观众互动；留给观众的最多一个。禁止不答也不交给观众的无厘头设问。
6. **观点必须落地到证据**：引述型说清出处主体；原创判断型后面紧跟 2-3 个有明确出处、来自联网检索最新权威信源的论据。光秃秃论断补证据或删。
7. **主权与合规红线（二值，不可协商）**：港澳台不能与"中国"并列（写"中国大陆和香港/台湾地区"），台湾是中国一部分、不得暗示其为独立国家；主权领土敏感表述以官方口径为准。普通观众未必注意，但出错即重大事故，由硬门禁兜底、不靠受众复审去碰。

### 第二层·受众复审（以真实观众的认知与口吻逐段重读）

硬门禁抓"作者勾选就能发现"的硬伤；这一层抓作者自己看不出来的"误判受众"类 AI 味。生成产物时把本账号目标受众画像、受众心声注入这一段，让审核者具体地"变成那个观众"。审核者的认知水位以 **Step 0 的公共认知水位**为准。以观众身份逐段吐槽，凡触发下面任一句就标红：

- "这我早就知道了啊" → 把人尽皆知的事当猛料揭（假澄清、假反常识、把常识当独家）。
- "你这是在教我做人？当我傻？" → 居高临下、预设观众无知的措辞。
- "所以呢？这到底跟我有啥关系" → 抛了"跟你有关"的钩子却甩宏大叙事，没落到切身可感的好处/威胁。
- "这开头不够让我停下来" → hook 没锚在最切身、利害最大的点上。
- "这段我划走了" → 过场、铺垫、正确的废话，没有信息往前推。
- "这句是把大结论当事实甩给我——凭啥？" → 强事实论断后面没跟可查依据的，标红：指出缺论据、回去补信源（真假由硬门禁第3/6条把关）。
- "这例子我没听过/想半天没懂" → 举例违反"举例两关"：例子比要讲的点更陌生，或不在受众日常经验里（如给国人讲浏览器挂锁图标）。抓出来，换更近的例子或删。

### 第三层·留存型内容的事实与立场终审（留存导向写法为抓人会主动加具体、下judgement、抛反直觉结论，这几样最容易出事且作者自查不出）

1. **真信源关（编造的具体最危险）**：把全文每一处"具体的外部事实"（数据、实验、事故、机构、人名、时间、排名）拎出来逐条问：有真实信源吗？✓真实事件标出处+时间、不确定就明说；✓虚构人物用"我一个朋友…"演绎框；✗把编造的实验/事故/数据伪装成真实（"国际上做过大规模实验"却给不出是谁做的）。**编造的具体比笼统的抽象更糟——它最像真的，最能同时骗过观众和作者，无联网时尤其高发。** 无源的具体事实逐条标出，补真信源或降级为泛化/删除。
2. **因果闭环关**：每个反直觉结论后面因果链必须补严、一步步讲清"为什么"，留了洞的反直觉结论就是标题党（高点击低完播、伤信任）。抄出结论句检查论证链有没有跳步。
3. **敏感/监管题立场关**：涉监管、政策、公共安全、民族/主权等敏感题，姿态不能是"揭穿骗局/唱反调"，落点收到安全区（"我理解监管为什么这么做""最后是为了大家的安全"），而非暗讽产品/制度。
4. **可执行正向收尾关**：结尾不能只留文艺/消极/空茫的情绪，要给观众一个能带走的、可执行的、正向的东西——从防御性焦虑转成主动掌控感，更利收藏转发。

> **终审已独立成模块**：生成产物时，上述三层终审逻辑落地为独立的 [审查模块](script-review.md)（与选题/标题/封面/文稿并列的第五个模块），文稿模块末尾引导"写完走审查模块"，由审查模块承载完整的"换一双眼睛"终审。本方法论此处保留三层逻辑的内核，供生成审查模块时作底座。

### 终审判决（必须写出来，作为后续任何收尾步骤的前置凭据）
- **PASS**：硬门禁 7 条全过 + 受众复审无触发，逐条写出结论（不是"都过了"三个字）。
- **打回**：问题原句 + 病灶 + 改法，回写作重改，改完重走终审。

> 若产物带"存档到内容库"等收尾步骤，必须放在拿到终审 PASS 之后，并以贴出 PASS 判决原文为前置条件——收尾脚本会报错逼人处理，终审不会报错，正因如此更要防止"先做会报错的、把不报错的终审甩在后面"。
