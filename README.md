# huasheng-skill-creator

**视频创作工作流生成器** —— 一个「生成 skill 的 skill」。

它不直接帮你写某一条视频的选题、文稿、封面，而是通过极简访谈 + 联网研究，为你的账号量身**生成一套独立、可安装、开箱即用的专属视频创作工作流 skill**，覆盖从选题 → 文稿 → 标题 → 封面的完整链路，并把最终成片收口到**花生 AI**（素材剪辑 + MG 动画 + 本地素材，口播驱动）。目标是让内容更适配平台算法（播放量、完播率、播放时长、封面/标题 CTR、互动），帮账号找到目标受众、做出优质内容、被算法青睐，且产出能直接落到花生 AI 成片。

支持平台：**抖音、B站、小红书、视频号、百家号**。最终成片工具：**花生 AI**。

## 核心思路

通用的"帮我写标题"提示词产出的是通用结果。真正能起量的账号，需要一套贴合自己**平台算法 × 垂类特性 × 账号人设**的作战手册。本项目把这套定制过程自动化：

1. **只问三件事（+ 可选对标账号）** —— 平台、垂类、人设；有想参考的对标账号也可以给，用来加速搭建和做差异化。
2. **自己做功课** —— 联网研究受众画像、爆款共性、竞品格局、变现路径、平台算法动向，有对标账号则额外拆解其打法，叠加内置的五大平台算法知识库。
3. **先给诊断，再造工具** —— 产出「账号定位诊断 + 策略提案」让你确认方向，确认后才生成产物 skill。
4. **产物自包含，收口花生 AI** —— 生成的工作流 skill 独立可用，把平台算法事实直接注入各模块；文稿只输出纯口播稿，可直接粘进花生 AI 成片。

## 仓库结构

```
huasheng-skill-creator/
├── huasheng-skill-creator/     # ⭐ skill 本体（安装这个目录）
│   ├── SKILL.md                # 生成器主流程（五阶段：访谈→研究→诊断→生成→交付）
│   ├── README.md               # skill 详细使用说明
│   ├── references/
│   │   ├── platforms/          # 五大平台算法知识库（各含四层拆解）
│   │   ├── methodology/        # 四份跨垂类方法论内核（选题/文稿/标题/封面）
│   │   ├── exemplars/          # 金标准范例
│   │   └── skill-template/     # 产物骨架模板
│   ├── scripts/                # 封面生成脚本 + 结构校验器
│   └── tests/                  # 单元测试
└── docs/superpowers/           # 设计文档与实现计划
```

## 快速开始

把 `huasheng-skill-creator/` 目录放到 Claude Code 的 skills 目录下：

- **Claude Code**：`~/.claude/skills/huasheng-skill-creator`

安装封面生成依赖：

```bash
pip install openai
```

然后直接说出需求即可触发，例如："我想在小红书做家庭理财内容，人设是二胎宝妈"。

详细使用说明见 [`huasheng-skill-creator/README.md`](huasheng-skill-creator/README.md)。

## 安全说明

封面生成脚本用环境变量 `LLM_GATEWAY_API_KEY` 读取密钥。**真实密钥只写进产物目录下 git-ignored 的 `.env` 文件**，随技能追踪的 `.env.example` 只放占位符，任何真实密钥都不会硬编码进被版本控制追踪的文件。
